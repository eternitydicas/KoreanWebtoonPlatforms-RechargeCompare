数据说明与规则
  • 数量 A+B：A = 永久币，B = 限时币（限时多久各平台规则不同，详见各平台下方「注」）
  • 带 p 的数字是积分，不是币：如 Lezhin 首充的「399+16000p」= 399 永久币 + 16000 限时积分。积分只能在部分内容上抵用，与币不是一回事；本页的 Per 值与「按数量对比」都只按币计算，积分不计入数量
  • 限时币2个月 表示限时币有效期 2 个月
  • 带 iOS 港区 列的表：该组以 港币 计价，按实时港币汇率折算RMB再算 Per 值；iOS 港区币数与网页档位可能不同，分开标注
  • 需抢 表示限量、需要抢的档位（历史月份默认 70% 与 60% 档，个别档位另标），绿色底标出
  • Best 表示同表内 Per 值最低的档位
  • Per 值 = RMB价格 ÷ 计算基数 × 系数，均按实时汇率动态计算
  • 顶部「对比模式」可同时挑 最多 4 个分区（可跨平台：如 Lezhin 首充 vs 韩bom 双倍 vs Ridi 首充）比较，每行最多并排 2 个（窄屏自动变单列），按 Per 值排名；填了「想买 N 个」后改按「凑够 N 个的最省买法」排序，单档不够时会多档组合（可关闭）
  • 顶部「今日花费」按 平台 → 活动 → 档次 三级下拉选好，立刻算出该档在各渠道折合 RMB 的价格与最省渠道，可「加入今日清单」累计今天总共要花多少；活动里还有「✎ 自定义金额」，可把表里没有的新组合（价格 + 数量）自己填进去算 RMB 与 Per 并计入清单
  • 顶部「自助计算」：自己填 币种（韩元 / 美元 / 日元 / 港币 / 人民币）+ 价格 + 实得数量，实时按所选平台的指标算出折合 RMB 与各档 Per（Lezhin 是 Per/1c·2c·3c，Ridi·Mrblue 是 Per/100…600，Tappytoon 是 Per/100P…400P），可累积多条横向对比，按平台自动分组
  • 对比模式除了「按数量」（想买 N 个，谁最省），还能「按 RMB 预算」（手里 ¥X，各项最多能买到多少）；两者二选一，填一个另一个自动清空
  • 顶部「备忘录」：随手记平台相关的事（返币、到期日、活动规则…），可以指定平台也可以不指定，带日期、按天分组，存在本机浏览器里
